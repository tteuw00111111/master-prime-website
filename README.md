# Website for Master Prime Technologies

A modern, responsive, and fast-loading website built for a local repair technician to showcase their services, build trust with customers, and generate leads.

## 🛠️ Tech Stack

-   **Framework:** [Next.js](https://nextjs.org/)
-   **Library:** [React](https://reactjs.org/)
-   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
-   **Deployment:** [Vercel](https://vercel.com/)
