## Clusters reservados para futuras páginas completas

Estas intenções têm conteúdo real, mas não receberam novas URLs nesta implementação porque o site não possui sistema de rotas para conteúdo e a tarefa proíbe criação automática que exija redesign. Se forem criadas no futuro, devem reutilizar os componentes e a identidade visual atuais:

- conserto de celular Campo Grande;
- conserto de notebook Campo Grande;
- manutenção de computador Campo Grande;
- conserto de impressora Campo Grande;
- conserto de videogame e controle Campo Grande;
- PC gamer Campo Grande.

Não criar uma URL para cada bairro. Campo Grande, Bangu, Cosmos, Realengo, Guaratiba, Paciência, Santa Cruz e Santíssimo permanecem como áreas atendidas na FAQ e no `areaServed`.
